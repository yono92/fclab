## 2. FCLab 차별화 포지셔닝

### 한 줄 정의
> **"통계로 증명하는 FC Online 플레이 분석 플랫폼"**

### ZDQD vs FCLab 차별화

| | ZDQD (AI 요약형) | FCLab (통계 근거형) |
|---|---|---|
| 분석 방식 | LLM이 경기 요약 생성 | 통계 지표 기반 정량 분석 |
| 근거 제시 | "당신은 패스형 플레이어입니다" | "최근 20경기 숏패스 성공률 87.2% (상위 12%), 롱패스 41.3% (하위 38%)" |
| 비교 대상 | 일반적인 메타 참고 | 같은 등급대 유저 분포 + 랭커 분포 이중 비교 |
| 액션 제안 | "빌드업을 개선하세요" | "박스 내 슈팅 비율 23% → 상위권 평균 41%. 스루패스 시도 +3회/경기 권장" |
| 변화 추적 | 현재 스냅샷 | 주간/월간 트렌드 차트 |
| 신뢰 표기 | 없음 | 표본 수, 신뢰구간, 갱신 시각, API 반영 지연 명시 |

### 통계학과의 강점이 녹아드는 포인트

1. **분포 시각화**: 단순 평균이 아닌, 히스토그램/박스플롯으로 "내가 전체 유저 중 어디에 있는지" 표현
2. **백분위(Percentile)**: "당신의 유효슈팅률은 상위 15%입니다" — 직관적이고 강력
3. **신뢰구간**: "표본 20경기 기준, 승률 60% ± 8%p (95% CI)" — 데이터 양이 적을 때 과대해석 방지
4. **효과 크기(Effect Size)**: "이 선수를 넣었을 때 골 기대값이 +0.3 상승" — 단순 비교를 넘어선 인과 추정
5. **상관분석**: "점유율과 승률의 상관계수 r=0.12 → 점유율이 높다고 이기는 게 아닙니다"
6. **이상치 탐지**: "이 경기는 평소 패턴과 크게 다릅니다 (z-score > 2.5)" — 이상 경기 자동 플래그
7. **가중 이동평균**: 최근 경기에 더 높은 가중치 → 현재 폼 반영
8. **A/B 비교 프레임**: "포메이션 A (10경기) vs B (15경기): 승률 차이 20%p, p-value 0.03"

## 3. MVP 범위 추천

### Phase 0: 기반 (1주)
- [ ] Next.js 프로젝트 셋업 (App Router)
- [ ] Supabase 프로젝트 연동
- [ ] Nexon API 프록시 (Edge Function, API Key 보호)
- [ ] 메타데이터 동기화 (선수, 시즌, 포지션, 등급)

### Phase 1: MVP 코어 — "내 플레이 리포트" (2-3주)
> 유저가 닉네임 입력하면 통계 기반 분석 리포트를 받는다

- [ ] 닉네임 검색 → OUID → 최근 N경기 데이터 수집
- [ ] **종합 대시보드**
  - 승/무/패 비율 (도넛 차트)
  - 최근 폼 (가중 이동평균 승률 라인 차트)
  - 매치 타입별 통계
- [ ] **슈팅 분석**
  - 슈팅 위치 히트맵 (x, y 좌표 기반)
  - 유효슈팅률, 골 전환율 백분위
  - 슈팅 유형별 분포 (헤딩/프리킥/페널티/인박스/아웃박스)
- [ ] **패스 분석**
  - 패스 성공률 분포 (숏/롱/스루/로빙)
  - 패스 유형 비율 레이더 차트
- [ ] **수비 분석**
  - 태클/블록 성공률
  - 실점 시간대 히스토그램
- [ ] **선수별 퍼포먼스**
  - 주요 사용 선수 TOP 10
  - 선수별 경기당 평균 (골, 어시, 패스, 평점)
  - spRating 분포

### Phase 2: 차별화 — "나 vs 랭커" (2주)
- [ ] 랭커 스탯 수집 & 집계 (ranker-stats API)
- [ ] **포지션별 비교 패널**
  - 내 선수 vs 랭커 평균 (같은 선수, 같은 포지션)
  - 스탯 레이더 차트 오버레이
  - 차이가 큰 지표 하이라이트
- [ ] **백분위 게이지**
  - 각 지표를 전체 유저 분포 내에서 위치 표시
- [ ] **메타 두 층 분리**
  - 랭커 메타 (TOP 10,000) vs 일반 유저 메타
  - 선수 사용률, 포지션 배치 비교

### Phase 3: 성장 — "변화 추적 & 액션 제안" (2주)
- [ ] 검색 기록 Supabase 저장 (시계열 데이터)
- [ ] **주간/월간 트렌드**
  - 승률, 점유율, 유효슈팅률 등 핵심 지표 시계열 차트
  - 이동평균 + 추세선
- [ ] **액션 제안 엔진**
  - 규칙 기반 (통계 임계값 → 제안 매핑)
  - "박스 내 슈팅 비율이 하위 30% → 침투 빈도 높이기 권장"
  - 표본 수 & 신뢰도 배지 표시
- [ ] **이상 경기 플래그**
  - z-score 기반 이상치 자동 감지

### Phase 4: 확장 (이후)
- [ ] 상대 공략 (최근 상대 검색 → 약점 분석)
- [ ] 포메이션/전술 A/B 비교
- [ ] 선수 추천 엔진
- [ ] 알림 (등급 변화, 메타 변동)

## 4. 신뢰 UX 원칙 (모든 페이지 공통)

모든 분석 결과에 반드시 포함할 것:

```
┌─────────────────────────────────────────────┐
│  📊 분석 기준                                │
│  ─────────────────────────────────────────── │
│  표본: 최근 20경기 (공식경기)                  │
│  기간: 2026-03-15 ~ 2026-04-01               │
│  갱신: 2026-04-02 13:00 (API 반영 ~2시간 지연) │
│  신뢰도: ██████████░░ 충분 (n≥15)             │
└─────────────────────────────────────────────┘
```

- **n < 5**: "데이터 부족 — 참고용으로만 활용하세요"
- **5 ≤ n < 15**: "제한적 — 추세 참고 가능, 정밀 분석엔 경기 수 추가 필요"
- **n ≥ 15**: "충분 — 통계적으로 유의미한 분석 가능"

## 5. 기술 아키텍처 (MVP 기준)

```
[유저] → [Next.js Frontend]
              │
              ├── 검색 → [API Route / Edge Function]
              │              │
              │              ├── Nexon API (실시간 조회)
              │              └── Supabase (캐시/저장)
              │
              ├── 분석 리포트 → [Server Component]
              │                    │
              │                    ├── 통계 연산 (서버사이드)
              │                    └── 차트 렌더링 (클라이언트)
              │
              └── 랭커 비교 → [Supabase 집계 테이블]

[Cron Job] → 메타데이터 동기화 (daily)
           → 랭커 스탯 수집 (hourly)
```
