## 1. ZDQD (https://www.zdqd.kr/)

### 포지션: AI 분석형 전적검색

### 기능 상세

| 기능 | 세부 내용 | FCLab 대응 |
|------|---------|-----------|
| **전적 분석** | 승률, 점유율, 슈팅, 패스 성공률 등 핵심 지표 대시보드 | 동일 + 백분위 추가 |
| **AI 리포트** | LLM이 강점/약점 진단 + 약점 보완 추천 선수 제안 | 규칙 기반 액션 제안 (근거 명시) |
| **상대 공략** | 상대 닉네임 입력 → 선호 포메이션, 공격 루트, 수비 취약점 분석 | Phase 5 (v2) |
| **메타 분석** | TOP 10,000 랭커의 실제 선수/팀컬러/포메이션 | 동일 + 일반 유저 메타 분리 |

### UI/UX 특징
- 다크 테마 기본 (라이트 모드 옵션)
- 그래디언트 기반 아이콘 (파란/보라/초록/사이안)
- 카드형 레이아웃
- 3단계 사용 프로세스: 닉네임 입력 → AI 분석 → 상대 공략
- FAQ 6개 항목
- 가이드 페이지: 지표별 해석 방법 설명

### 강점 분석
1. **올인원 흐름**: 전적 → AI 분석 → 상대 공략이 한 흐름
2. **AI 차별화 메시지**: "AI가 분석해준다"는 마케팅이 강력
3. **선수 추천**: 약점 보완 선수를 직접 제안 (실용적)

### 약점 분석 (FCLab 기회)
1. **근거 부재**: "당신은 패스형입니다" → 왜? 어떤 수치 기준?
2. **신뢰도 미표기**: 몇 경기 기반인지, 언제 갱신됐는지 불명
3. **변화 추적 없음**: 현재 스냅샷만 제공
4. **백분위 없음**: "패스 성공률 85%" → 이게 높은 건지 낮은 건지 모름
5. **AI 블랙박스**: LLM 응답을 그대로 보여줘서 일관성/정확성 리스크

### FCLab vs ZDQD 차별화 포인트

```
ZDQD: "AI가 당신의 플레이를 분석했습니다: 패스형 플레이어"
FCLab: "숏패스 성공률 92.1% (상위 8%), 롱패스 41.3% (하위 38%)
       → 빌드업형 플레이어 (점수 78/100)
       💡 롱패스 성공률이 하위 38%입니다. 숏패스 빌드업을 유지하거나
          롱패스 타이밍을 개선하세요.
       📊 20경기 기준 · 95% 신뢰구간: 36%~47%"
```

## 2. 공식 데이터센터 (https://fconline.nexon.com/datacenter)

### 포지션: 공식 데이터 포털

### 기능 상세

| 기능 | 세부 내용 | FCLab 대응 |
|------|---------|-----------|
| **랭킹** | 매치타입별 전체 랭킹 조회 | 직접 경쟁 X, 보완재 |
| **선수 DB** | 전체 선수 스탯, 시즌별 카드 | 메타 분석 시 참고 |
| **팀컬러** | 팀컬러 조합 시뮬레이터 | 범위 밖 |
| **스쿼드 메이커** | 포메이션 + 선수 배치 시뮬 | 범위 밖 |
| **포메이션** | 인기 포메이션 통계 | 메타 대시보드에서 제공 |

### 강점
- 공식 데이터 → 절대 신뢰도
- 가장 넓은 데이터 범위
- 선수 카드 이미지/스탯 완비

### 약점 (FCLab 기회)
- **개인 맞춤 분석 없음**: 데이터만 나열, 해석 없음
- **"그래서 뭘 바꾸라는 건지" 없음**: 액션 제안 전무
- **비교 기능 부재**: 나 vs 랭커 비교 불가
- **트렌드 없음**: 현재 데이터만

### FCLab 포지션
공식과 정면 경쟁이 아닌 **상위 보완재**. 공식이 "데이터"를 제공하면, FCLab은 "해석"을 제공.

## 3. FCON.kr (https://fcon.kr/)

### 포지션: 경량 전적검색

### 기능 상세
- 닉네임 검색 → 최근 공식경기 전적
- 승률, 상세 경기 분석
- 추천 메타 (준비 중으로 보임)
- 경기 전술 (준비 중으로 보임)

### 강점
- 심플하고 빠른 UX
- 검색 → 결과 즉시
- 불필요한 기능 없이 핵심만

### 약점
- 메타/전술 페이지 미완성
- 분석 깊이 부족
- 확장성 제한적

### FCLab과의 관계
직접 경쟁보다는 타깃이 다름. FCON은 "빠르게 전적 확인", FCLab은 "깊게 분석".

## 4. FC INNO (https://www.fcinno.com/)

### 포지션: 유틸 통합형

### 기능 상세
- **구단주 검색**: 전적 조회
- **선수 검색**: 선수 DB + 스탯 조회
- **스쿼드 메이커**: 포메이션 구성 도구
- **강화재료**: 강화 비용 계산

### 강점
- 유틸 묶음이 강력 (검색 + 스쿼드 + 강화)
- 한 사이트에서 여러 용도 해결

### 약점
- "분석"보다 "도구" 성격
- 실력 향상 인사이트 없음
- 데이터 나열 위주

### FCLab과의 관계
겹치는 영역 적음. FC INNO는 "게임 유틸", FCLab은 "실력 분석". 상호 보완 가능.

## 핵심 벤치마크 결론

1. **ZDQD가 유일한 실질적 경쟁자**. 나머지는 카테고리가 다름
2. **ZDQD의 "AI" vs FCLab의 "통계"** — 이 프레이밍이 승부처
3. **공식은 적이 아니라 데이터 소스**. 해석 레이어로 보완
4. **ZDQD에 없는 것**: 백분위, 신뢰구간, 변화 추적, 메타 두 층 분리, 신뢰도 배지
5. **ZDQD에 있지만 FCLab이 더 잘할 수 있는 것**: 근거 기반 액션 제안
6. **ZDQD에 있고 FCLab이 나중에 할 것**: 상대 공략, 선수 추천
